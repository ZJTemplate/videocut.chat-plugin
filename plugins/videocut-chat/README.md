# videocut.chat

**用自然语言剪辑，交付视频与可编辑工程。**

插件版本：**0.3.3**。包含视频剪辑 skill、三种内置样式预览，以及 Codex / Claude / Qwen 的兼容配置。

- [安装、授权与升级](https://github.com/ZJTemplate/videocut.chat-plugin/blob/main/docs/INSTALL.zh-CN.md)
- [MCP、REST 与 n8n 接入](https://github.com/ZJTemplate/videocut.chat-plugin/blob/main/docs/INTEGRATIONS.zh-CN.md)
- [更新记录与下载](https://github.com/ZJTemplate/videocut.chat-plugin/releases/tag/v0.3.3)
- [Skill 指令](skills/videocut-chat-video/SKILL.md)

本地使用需先运行仓库的隔离安装器，再使用其生成的机器适配插件。仅下载此 ZIP 不会自动安装 Python 依赖、渲染运行时或完成账户授权。

本地 SDK 与在线服务分别更新；可用功能以 `saycut_capabilities` 为准。
