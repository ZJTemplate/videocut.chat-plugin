# 0.2.2 发布后验收

日期：2026-09-14。结论：可用于协助配置的本地内测；远程技术链路可用，但普通用户自助授权、全部花字和商业计费尚未打通，不能宣称全面上线。

## 验证来源

- 从公开 GitHub 仓库重新克隆，检查提交 `0d577ff1c8b8c939bf432639705c2d1e2b65281b` 的发行文件。
- `saycut_tools-0.2.2-py3-none-any.whl`、插件 ZIP 的 SHA256 和 ZIP 完整性通过。
- 使用新建私有 Python 环境分别运行基础安装和 `--asr` 安装，依赖安装与 `pip check` 通过，没有修改全局 pip 或已有插件环境。
- 本地合成复用已获授权的运行时、资源、字体、ASR 模型缓存和账号。不是一台完全空白电脑上的零配置成片验收。
- n8n 2.38.7 使用独立安装和数据库实际执行工作流，不是仅检查 JSON 或模拟 HTTP。
- 所有媒体为测试合成素材；经用户允许，共提交两个短视频云端合成任务。

## 已发现的限制

1. 本地公开包是 0.2.2，线上 FC 仍报告 0.2.1。推送发行仓库不会部署服务端。
2. 线上采用旧版 GenVideo 协议，仅开放 `runtime/ZapMotion`。自动识别可用，但不接受自定义字幕、语言选择、效果参数或完整工程，不返回可编辑工程。把 FC 升级到 0.2.2 本身也不会自动完成远端 worker 升级。
3. 用户 token 当前 scope 为 `account:read license:local`，与远程视频网关凭据不是同一授权链路。
4. 新配置安装后没有已绑定花字，诊断返回 `styles_missing`。运行时、资源和字体仍需获取与配置，ASR 模型须明确下载。已有配置保留，因此后续加 `--asr` 不会自动修改旧配置中的 disabled。
5. SDK 本地路径权限检查有效：测试素材不在 allowed_roots 时被拒绝；补充测试配置的允许目录后才执行，未改变用户原配置。
6. 云端估价实现仍为 `cloud_unpriced`，本次未验收按个人账户扣点、失败返点或实际账单金额。上游任务服务可能另行计费。
7. editor_bridge_enabled 为 false；不能将交接链接描述成已经支持 edit.videocut.chat 在线编辑。
8. 完整 ASR 测试只覆盖清晰的短中文合成语音，不代表噪声、方言、多人、长视频均已验收。花字抽帧不代表每一帧全部可读。

## n8n 使用材料

可导入示例及中英文说明在 [examples/n8n](../examples/n8n/README.md)。示例无 token，需在 n8n 凭据管理中配置另行开通的网关凭据。

- [MCP 连通性检查](../examples/n8n/mcp-check.json)：不上传、不生成任务。
- [云端合成子工作流](../examples/n8n/cloud-render.json)：输入已经完成上传的 asset_id，输出任务结果。
- 子工作流不是上传表单。须先申请 OSS 上传、PUT 二进制、确认上传；本机路径不能直接交给 FC 或 n8n Cloud。
- 基础安装器默认导出的 n8n 模板指向本地 `127.0.0.1:8765`，它不表示远程服务地址。上述远程示例明确使用 mcp.zjtemplate.com。
- 原生 MCP Client 输出可能在 structuredContent 中，REST 节点输出则是业务 JSON；两者不能不加处理地互换。
- 自定义节点的修复位于服务端源码，未包含在 Python wheel 中，也未发布到 npm。原生节点示例不依赖它。
