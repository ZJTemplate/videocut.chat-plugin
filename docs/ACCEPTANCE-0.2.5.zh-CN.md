## 实际发现与修复

1. **新安装不能本地合成**：默认 MCP 域名仍拼接旧 `/business/verify-license`，返回 404。现在插件适配层统一使用 `/mcp/v1/license/check` 并转成 SDK 需要的旧响应结构；严格校验布尔结果、HTTPS 证书，禁止跳转。两个官方域名的旧授权配置均完成真实合成。
2. **新旧插件共用授权配置不兼容**：仅允许两个精确的官方来源共享连接，保存时保留旧插件可识别的来源记录；第三方来源仍隔离。
3. **横竖屏混排会拉伸**：增加本地 `clip.fit=contain/cover`，通过原生引擎现有缩放参数实现。默认省略字段继续保持旧工程行为。
4. **错误输入和临时文件可导致失败**：空/损坏字幕、非法原生参数、不可显示文本、重复修改 ID、过期工程版本、畸形厂商参数在执行前拒绝；半截进度 JSON 和超大数值不会终止渲染。厂商执行授权必须是布尔 `true`，异常执行不会被标记为可无条件重试。
5. **CI 安装成功但 FC 打包失败**：新 SQLAlchemy 源码版本暂无对应 Linux wheel。CI 改为只选择它已发布的二进制版本，随后部署成功；插件二进制无需改变。

## 效果与效率

- 横屏素材转 360×640 竖屏，测试方块在旧拉伸下变成约 56×176 像素；`contain` 为 56×56，`cover` 约 174×176。前者保留全画面并留黑边，后者居中裁切。
- 带旋转标记、非方形像素及旧导入元数据不直接假定正确。显式适配会要求重新导入/FFmpeg 标准化；标准化后重新验证通过。旧拉伸用例通过只表示行为兼容，不表示画面比例正确。
- 逐句位置和颜色修改后，抽帧确认两句字幕分离、颜色正确。
- 真实 ASR 加花字用例约 7.92 秒；3 秒短片编辑合成约 4.12 秒；8 秒 1080p60 合成期间注入 88 次半截进度文件，约 10.23 秒完成。均为本机单次样例，不是固定耗时保证。
- 预检 1/10/100 句字幕的三次中位数约为 0.0016/0.0114/0.1042 秒；1000 句约 1.0556 秒后命中 `staging_limit`，不能称作 1000 句成功合成。字体按字幕暂存会影响预算，需要后续资源复用优化或分段。
- 重叠、过小字号、过短动效和字形覆盖提供风险提示；告警最多返回 20 条明细，不是像素级避碰或自动排版保证。

## 云端结果

0.2.5 部署后 3/3 真实任务成功，均经历 `queued -> running -> succeeded`，幂等重试返回原任务，无查询错误，下载文件均通过媒体探测及字幕抽帧检查。

| Case | 输入与入口 | 上传耗时 | 上传至下载 | 输出 |
| --- | --- | --- | --- | --- |
| C1 | 中文 5.4 秒，MCP | 0.29 秒 | 66.31 秒 | 640×360，5.4167 秒 MP4 |
| C2 | 英文约 86 秒，REST | 0.44 秒 | 65.74 秒 | 640×360，85.96 秒 MP4 |
| C3 | 中文 5.4 秒，REST 重复素材 | 0.36 秒 | 96.29 秒 | 640×360，5.4167 秒 MP4 |

MCP 协商版本 `2025-11-25`，云端暴露 23 个工具。连续 10 次 REST 能力查询约 20–61 毫秒，中位数 21 毫秒。这只是同网络小样本，不代表高并发、冷启动或其他地区延迟；也不能由接口延迟推断渲染速度。

三个任务仍返回空用量和不可编辑输出，使用运营验收凭据。短片也需约一分钟，当前未达到即时合成体验；需要在实际 worker 上进一步定位排队、初始化和轮询的耗时，不能把本次英文任务更快解释为已完成性能优化。

作为对照，本轮先部署的 0.2.4 三次真实云端任务均完成：中文约 5.4 秒、英文约 86 秒、中文重复素材；上传至下载分别约 66.53/96.80/96.73 秒。请求经过 FC、远端 worker、上传和下载，不是在当前电脑替代云端合成。

## 未完成与已知限制

- 云端旧 worker 只开放一个预设和 MP4，没有本地全部花字、逐句参数、显式 `fit`、手工定时字幕或可编辑云端工程。请求不支持的功能应明确拒绝，不能静默丢参数。
- 旧 worker 返回 `usage={}`，按现有规则最终计量为 0。本轮使用运营验收凭据，不能证明个人 OAuth、余额预留、实际扣费和返点全链路已经验收。
- 云端全能力和计量升级需要实际 Mac mini worker 的部署入口；发现本机 widget 源码并不等于已经升级远端机器。
- `edit.videocut.chat` 的编辑器桥接尚未部署，不能宣称链接可直接完成在线编辑。
- 特殊原始 MCP 帧中的孤立 Unicode 代理字符可能被 MCP 2.2.0 传输层丢弃而不返回错误；后续正常工具请求可继续。官方客户端在发送前拒绝这种字符。
- 长字幕换行、字体缺字、装饰越界及极短动效仍需看成片。211 个样式的完整短片遍历来自此前 0.2.3 验收，本轮没有把它重复计为 0.2.5 新测 211 项。
- Windows/Linux 原生渲染、各厂商消费聊天入口、模型自主选择参数、个人 OAuth UI、生产负载与长期稳定性没有完整验收。
- 发布 wheel/ZIP 不会自动更新宿主缓存；既有安装需升级。没有向 PyPI、官方 Codex/Claude 市场提交此版本。
