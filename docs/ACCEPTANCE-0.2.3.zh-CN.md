# 0.2.3 修复验收

日期：2026-09-14。状态：受控内测，不能据此宣称全部云端能力已开放。

## 修复及验证

| 项目 | 本轮结果 |
| --- | --- |
| 部署 | 主 API、前端与独立 FC 的 GitHub Actions 均成功；线上 FC 报告 0.2.3 |
| 数据库 | 在现有 RDS 增加两张 OAuth 表，没有重置原账号/连接/证书，也没有更改用户余额字段类型 |
| OAuth | 发现、动态注册、PKCE、一次性授权码、刷新轮换/重放拦截、撤销与资源绑定已实现；隔离回归通过 |
| 权限隔离 | 本地 `license:local` 不自动获得 `video:cloud`，跨用户任务不可读，旧本地账号真实刷新成功 |
| 计费 | 读取现有 GenVideo 数值价格；事务预扣、幂等、余额不足拒绝、成功差额退款与失败一次性退款通过隔离回归 |
| 新安装 | 独立安装器及 pip check 通过，全局 pip 未改变；自动准备固定版本原生运行时和 211 个样式资源 |
| 本地合成 | 实际通过 wheel 的 MCP stdio 调用 27 个工具中的合成链路；中文 ASR 返回 19 个词级时间单元，花字颜色和缩放修改后再次导出 |
| 输出检查 | 两次真实 MP4 合成，H.264/AAC、640x360、约 5.417 秒；检查代表帧，332 文件可编辑 ZIP 的 CRC 通过 |
| n8n | 空 JSON、字符串/对象参数、两种认证、错误分支共 8 项契约检查通过；23 个视频操作齐全，OAuth 示例明确指向远程 |

本地验证使用全新安装的包与新下载/解包的发行资源，但复用了本机合法账号、FFmpeg 和 ASR 模型缓存；不是新账号或另一台空白电脑的零配置测试。未修改 C++ license 校验与续期。

隔离回归共 29 项，使用临时 SQLite 与测试身份；与实际线上账号测试区分。n8n 运营凭据的实际执行见 [0.2.2 历史记录](ACCEPTANCE-2026-09-14.zh-CN.md)，本轮请求契约模拟不冒充真实 n8n OAuth UI 登录。

## 尚待真实授权

已在线发起一次 0.2.3 OAuth 请求并提供平台授权链接，但十分钟内未收到浏览器回调，本地回调服务已结束，没有创建个人云端任务或产生本次任务扣款。需要重新发起请求并由用户亲自确认，才能继续令牌交换、个人云端合成与生产流水对账。不代替用户批准，也不把旧本地权限扩大为云端消费权限。

## 仍需远端工程配合

1. 实际 GenVideo worker 仓库/部署入口未提供，不能在这台桌面电脑运行一个 worker 代替。现网仍是一个预设和 MP4；本地 211 个样式、逐句参数和编辑工程尚未全量接通云端。
2. 已读取旧 worker 成功结果，其 `usage={}`。现有平台规则得到 0 元；不能伪造模块用量来扣费。自动 ASR 默认预留 6 元是时长上限担保，不是固定价格，真实完整计量需要 worker 改造。
3. 编辑器桥接尚未部署，不能宣称已有链接即可直接进入 `edit.videocut.chat` 编辑。
4. Windows/Linux 原生合成、所有 LLM 客户端、n8n Cloud 和 AI Agent 自主选工具尚未验收。上架主体资格、正式隐私/服务/数据保留政策仍需产品方准备。

新版本单独存放于 `releases/v0.2.3`，不覆盖 0.2.2；公开包不含数据库连接、SDK 证书、账号 token 或客户视频。
